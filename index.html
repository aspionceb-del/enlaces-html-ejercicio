🌐 Enlaces HTML entre archivos del servidor

Este ejercicio muestra cómo construir rutas relativas entre archivos HTML dentro de una estructura de carpetas. La tabla indica desde qué archivo se parte, a cuál se quiere enlazar, y cómo debe escribirse el atributo href en el enlace.

📁 Estructura del directorio

server/
├── arrel.html
├── fitxers/
│   └── carta.html
├── prova/
│   └── prova.html
├── subdir/
│   ├── docu.html
│   ├── llista.html
│   ├── index.html
│   └── direct/
│       └── textual.html
